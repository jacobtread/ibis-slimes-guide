This guide is not yet complete so all you get is pictures for now:

TLDR: Enter tracker into 6-side calibration mode by running the `6-side` command while plugged in, quickly unplug the tracker and rotate it to cover all the 18 axis points required using the stand model, the tracker light will flash while this is happening,
when you correctly place a tracker at a valid axis that hasn't been covered yet the light
will briefly go solid indicating that its capturing the data before blinking again, once the light starts blinking you can move to the next axis
